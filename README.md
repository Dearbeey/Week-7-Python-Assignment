#  Iris Dataset Analysis and Visualization

This Jupyter Notebook contains an end-to-end analysis and visualization of the classic Iris flower dataset using Python libraries such as **Pandas**, **Matplotlib**, **Seaborn**, and **Scikit-learn**.

---

## Objective

- Load and explore the Iris dataset
- Perform basic statistical analysis
- Create informative visualizations
- Draw insights from the data

---

## Dataset

The Iris dataset is built into `sklearn.datasets` and consists of:

- 150 samples of iris flowers
- 4 features: 
  - Sepal Length
  - Sepal Width
  - Petal Length
  - Petal Width
- 3 Species: Setosa, Versicolor, Virginica

---

## 📊 Visualizations Included

**Line Chart** – Petal length trend over samples
**Bar Chart** – Average petal length by species
**Histogram** – Distribution of sepal width with colorful bars
**Scatter Plot** – Sepal length vs. petal length by species
